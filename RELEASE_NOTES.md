При создании привычки можно выбрать дату начала. Дни с выбранной даты по вчера засчитываются в цепочку; сегодняшний день отмечается отдельно. Существующая история сохраняется.

Чекбокс выполнения расположен справа от названия привычки.

Чекбокс выполнения перенесён слева от названия привычки.

Рядом с названием chains на главном экране добавлен фирменный логотип цепочки.

Один экран: привычка, чекбокс и цепочка прогресса.

Первое выполнение заполняет первое звено слева. Число звеньев соответствует цели привычки. Убраны календарь, отдельные вкладки, даты под цепочкой и лишние подписи. Нажатие на привычку открывает её редактирование.

Привычки, история, напоминания и правила обрыва сохраняются. Обновление устанавливается поверх предыдущей версии.

Следующие версии собираются и публикуются через GitHub Actions. Проверка обновлений в приложении по-прежнему выполняется только по нажатию в настройках.
