# chains

Минималистичное Android-приложение для личных привычек. Android 8.0 и новее.

Один экран: название, отметка за сегодня, прогресс и цепочка. Первое выполнение заполняет первое звено слева; каждое следующее продолжает её. Количество звеньев соответствует цели. Нажатие на карточку открывает настройки привычки. Календаря и отдельных вкладок нет.

Цель и правило пропусков можно менять в любой момент. Есть напоминания и режим без обрыва. Сегодняшний день считается пропущенным только после полуночи. Изменение настроек не удаляет историю.

## Установка

[Последний APK](https://github.com/rnghx/chains-android/releases/latest/download/app.apk)

Обновления доступны по кнопке **Настройки → Обновить приложение**. Новые версии устанавливаются поверх предыдущих, с тем же идентификатором и подписью. Удалять приложение или очищать хранилище перед обновлением не нужно.

Привычки хранятся на телефоне, в SQLite. Они не отправляются на GitHub. В настройках есть сохранение и восстановление JSON-копии. Восстановление объединяет отметки, не удаляя существующие данные.

Для напоминаний разрешите уведомления Android. Пункт **Точные напоминания** открывает системное разрешение на Android 12+. Без него время может быть приблизительным. Принудительная остановка приложения и ограничения батареи телефона влияют на доставку уведомлений.

## Выпуск новых версий без хранения проекта на ПК

Код и архивы версий находятся в этом репозитории. Цифровая подпись сохранена в зашифрованных GitHub Actions Secrets: CHAINS_KEYSTORE_BASE64 и CHAINS_STORE_PASSWORD. По решению владельца приложение собирается на временном сервере GitHub Actions; локальные исходники, APK и копия подписи удалены после проверки облачного выпуска.

1. Измените код в репозитории. Увеличьте versionCode и versionName в app/build.gradle.
2. Обновите RELEASE_NOTES.md.
3. Откройте Actions → Signed Android release → Run workflow. Для публикации включите publish.

Сборка выполняет проверки, создаёт подписанный APK, сравнивает сертификат с исходным и публикует app.apk, source.zip и update.json. Без publish выполняется только проверка сборки. Ничего не устанавливается на телефон автоматически. Процесс запускается вручную, только доверенным владельцем репозитория.

Не меняйте существующие секреты подписи и applicationId. Не загружайте ключ в исходники или файлы релиза. Потеря исходной подписи лишит возможности устанавливать новые версии поверх существующего приложения. Миграции базы должны сохранять все привычки и отметки.

Система сборки: JDK 17, SDK 35, Build Tools 35.0.0, Gradle 8.13. Тесты проверяют серии, сохранение данных, импорт, экран привычек, заполнение первого звена и проверку обновлений. Установка на физическом телефоне не входит в автоматические проверки.
